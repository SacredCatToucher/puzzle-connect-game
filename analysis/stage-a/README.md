## 實際規則與獨立模型

棋盤為由左到右、由上到下的九格陣列，值為 0～8。
群組為四鄰接且相對目標位置正確的連通分量；不跨列環繞、不旋轉。
獨立模型以「目標座標減目前座標」相同的相鄰格建立連通分量，
與原遊戲逐方向比較目標座標的寫法不同。群組成員的列舉順序不是語意的一部分，測試排序後比較分割。

- from === to：原遊戲直接返回，不增加步數。
- 單格群組：與任意合法目標格交換，增加一步。
- 多格群組：以 from→to 的列、欄差平移；to 可位於同一群組內，也不必相鄰。
- 僅把平移後仍在棋盤內的成員納入 moved；不是整個群組出界就拒絕動作。
- S 是實際納入 moved 的來源格，D 是其目的格。S\D 與 D\S 各自按格子索引遞增排序；
  後者原本的拼圖依序回填前者。先從舊棋盤讀值，再寫入新棋盤。
- 被排除的越界成員不保證仍在原格：若其原格被覆蓋，它也會被納入 displaced 回填。
- 每次操作後依新棋盤重新判定群組，沒有永久群組 ID 或禁止拆組的條件。
- 完成棋盤仍可繼續操作；原遊戲沒有在完成後鎖住 move。

model.mjs 不讀寫 DOM、不修改輸入陣列，不會由遊戲載入。
公開 move 會額外檢查合法的 3×3 排列及格子索引，這是分析 API 的輸入保護；
對照測試的等價範圍是 UI 會提供的合法棋盤與 0～8 來源／目的格。

## 重複執行

在本分支的 repository 根目錄，以 Node.js 22 或更新版本執行，不需要 npm install：

~~~sh
node analysis/stage-a/model.test.mjs
~~~

失敗的 assertion 會中止並令 CLI 回傳非零；成功會輸出每個測試名稱與統計。
亦可 import runTests() 在支援 Node 模組的持續執行環境執行同一組測試。

- 81,342 次 move 結果及原遊戲步數對照，全部一致。
- 162,684 次群組分割對照（每次動作前後各一次），全部一致。
- 固定案例涵蓋單塊遠距交換、三格群組平移、群組內目標、重疊來源／目的、
  向右越界後拆成 3 與 6 格群組、極端對角越界、重新合併成九格群組及其後續動作、
  不得跨列連結、同格不計步、無效分析輸入拒絕。
- 四個固定棋盤各測全部 81 種來源／目的組合。

  實際含 840 個不同棋盤，每個樣本測全部 81 種來源／目的組合。
